# Third-party notices

## Ed25519 / SHA-512 (`src/sdk/hz_ed25519.h`)

The Ed25519 signature and SHA-512 code re-expresses the algorithm of
**TweetNaCl** by Daniel J. Bernstein, Bernard van Gastel, Wesley Janssen, Tanja
Lange, Peter Schwabe, and Sjaak Smetsers — a public-domain cryptographic
library (https://tweetnacl.cr.yp.to/). The constants and procedure follow that
reference; the implementation here is validated against the RFC 8032 Ed25519
test vectors.
